Fonctionnalités

Ce que fait l'administration, en plus des versions terrain

Intégration des envois terrain

Sélection multiple des fichiers reçus des agents (mail, clé USB, dossier partagé). Points déjà présents ignorés automatiquement par identifiant, aucun doublon.

Écriture directe sur disque

Via la File System Access API du navigateur — pas de compte, pas de serveur applicatif. Chrome, Edge ou Opera, poste de bureau uniquement.

Tableau et statistiques

Vue tableau exportable en CSV, histogramme mensuel par thématique — pour le suivi et le reporting, toujours calculé sur l'ensemble du fichier.

Correction et création de points

Saisie, modification et suppression directement sur le fichier central, en plus de l'intégration des envois terrain.

Mode d'emploi

Du point de vue de l'administrateur, en trois étapes.

Ouvrir le fichier central

« Ouvrir le fichier central » pour charger le fichier existant depuis le dossier réseau (lecteur mappé), ou en créer un nouveau si c'est la première utilisation.

Intégrer les envois terrain

« Intégrer un envoi terrain » : sélectionner un ou plusieurs fichiers reçus des agents (sélection multiple possible). Les points déjà présents sont ignorés automatiquement, pas de doublon.

Confirmer aux agents et sauvegarder

Une fois l'intégration vérifiée, prévenir les agents pour qu'ils effacent leur tablette (« Effacer les saisies en cours »). Garder une copie datée du fichier central régulièrement — c'est la donnée la plus précieuse du projet, le reste est régénérable.

Démonstration

Essayer avant d'intégrer ses propres envois terrain.

Un jeu de données d'exemple, points2.geojson, est disponible pour tester l'Administration sans avoir encore de fichier réel. Téléchargez-le, puis utilisez « Ouvrir le fichier central » pour le charger.

Votre fichier central réel restera ensuite en local — ce fichier de démonstration ne sert qu'à la découverte de l'outil.
